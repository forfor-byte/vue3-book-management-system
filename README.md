# 墨卷 · 图书管理系统 (Vue3 + TypeScript)

📚 一个基于 Vue 3 + TypeScript + Vite 构建的现代化图书后台管理系统，旨在提供流畅的图书借阅、读者管理与数据可视化体验。

## 🛠️ 技术栈

- **前端框架**：Vue 3 (Composition API, `<script setup>` 语法)
- **开发语言**：TypeScript (实现强类型约束，提升代码健壮性)
- **构建工具**：Vite (极速冷启动与热更新)
- **样式与布局**：原生 CSS3 (Flex / Grid 布局，响应式设计)
- **组件化开发**：深度拆分基础组件与业务视图组件

## ✨ 核心功能模块

- **数据看板 (Home)**：首页数据统计与图表概览。
- **基础信息管理**：包含图书管理、读者管理、分类管理。
- **业务流转**：借阅管理与归还状态追踪。
- **系统运营**：图书推荐、评论管理、统计分析。
- **响应式交互**：适配 PC 与移动端，侧边栏 (Sidebar) 在小屏幕下自动折叠。
